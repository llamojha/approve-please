Afterhours · migration record

What came back — and what stayed behind.

The refreshed desk is meant to make reviewing fast. This record explains which useful signals were restored from the legacy interface and why the remaining panels and behaviors were intentionally not ported.

7legacy treatments intentionally omitted

Restored in the live desk

Queue pressure

Restored

Velocity and Team trust now identify when the waiting queue is actively draining them. The cue is hidden in Learning mode because that mode disables queue penalties.

Shift statistics

Moved to dialog

Approved PRs, requested changes, escaped bugs, clean approvals, blocked bugs and false positives are available from the top bar. They no longer occupy permanent code-review space.

Display theme

Moved to settings

The light paper desk and an Afterhours dark desk are selectable and persisted locally. The restored control uses the new identity instead of reviving the GitHob imitation.

PR tags

Restored

Scenario tags return as compact chips below branch context. They help players scan domain and intent without competing with priority or revealing whether a PR is safe.

File language

Restored

Each diff file again identifies its language. This matters when a queue mixes code, documentation and configuration formats.

Intentionally not ported

Permanent right rail

Not ported

The old Metrics, Theme and Rulebook stack reduced the space available to the diff. Secondary information now opens on demand from the top bar while the active review remains the dominant surface.

Last-review receipt

Not ported

A persistent receipt would slow the core loop and conflict with the approved speed direction. Verdicts update meters, animate the coworker response and announce the outcome to assistive technology without waiting for acknowledgement.

Next-review arrow

Not ported

There is no manual Next action. Approve or Request changes commits the decision, performs the short swipe and loads the next queued PR automatically.

Repeated help panels

Consolidated

The legacy screen repeated line-tagging and verdict guidance around the diff and actions. First-run scenarios teach the interaction; the Review handbook remains available for recall.

Visible A / R badges

Consolidated

The shortcuts remain as Alt+A and Alt+R, but their legend lives in the handbook. Bare-letter shortcuts were avoided because they can conflict with browsing and assistive workflows.

Persistent coworker quote

Moved to handbook

The daily mantra stays in the shift bar. The longer quote remains available in the handbook, where it contributes personality without displacing code.

GitHob branding

Replaced

The imitation hosting-product skin was replaced by the Afterhours identity, coworker portraits and a paper/dark desk pair. Useful accessibility choices were retained without restoring the old parody styling.

Decision rule

Information needed to understand the current decision stays visible. Information useful for reflection or configuration remains one action away. Nothing may add an acknowledgement step between a verdict and the next review.

Prepared for preview PR #12 on 5 November 2026. This is a product and implementation decision record, not a user-research finding.
